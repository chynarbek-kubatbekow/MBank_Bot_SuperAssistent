# MBANK — Финансовый суперассистент
## Объединённый проект (Stage 2 + FinAI AI)

### Запуск
```bash
pip install flask flask-cors requests
python app.py
```
Открой: http://localhost:5000

### SQLite
Состояние демо хранится в локальном SQLite-файле `mbank_state.sqlite3`.
Путь можно заменить через переменную окружения:
```bash
set MBANK_DB_PATH=C:\path\to\mbank_state.sqlite3
python app.py
```

### Настройки окружения
Создай локальный `.env` рядом с `app.py` (он не попадёт в git) или задай переменные в терминале:
```bash
set GROQ_API_KEY=your_groq_key
set FLASK_DEBUG=1
set MBANK_CORS_ORIGINS=http://localhost:5000,http://127.0.0.1:5000
python app.py
```
Шаблон есть в `.env.example`.

### Что внутри
- **Дизайн**: Тёмная тема MBANK, зелёный #00C172, жёлтый акцент 10%
- **Функционал**: Весь из finai_stage2 (автоплан, риск-радар, теги, геймификация)
- **AI-ассистент**: Groq LLaMA 70B + fallback-режим без ключа
- **Шрифт**: Sora + JetBrains Mono
- **Demo mode**: Пульт для хакатонного показа рядом с телефоном: зарплата → риск → Sezim решает

### AI-ключ
Ключ Groq не хранится в коде. Если `GROQ_API_KEY` задан в `.env`, Sezim AI работает через Groq API. Если ключа нет, включается fallback-режим. Sezim может подготовить действия по переводам, счетам, целям, автоплану, офферам и миссиям, но выполнение идёт только после подтверждения пользователя.
