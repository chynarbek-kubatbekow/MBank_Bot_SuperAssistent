# MBANK — Финансовый суперассистент
## Объединённый проект (Stage 2 + FinAI AI)

### Запуск
```bash
pip install flask flask-cors requests
python app.py
```
Открой: http://localhost:5000

### Что внутри
- **Дизайн**: Тёмная тема MBANK, зелёный #00C172, жёлтый акцент 10%
- **Функционал**: Весь из finai_stage2 (автоплан, риск-радар, теги, геймификация)
- **AI-ассистент**: Groq LLaMA 70B + fallback-режим без ключа
- **Шрифт**: Sora + JetBrains Mono

### Экраны
| Экран | Описание |
|-------|----------|
| Главная | Баланс, автоплан-hero, NBA, офферы, теги |
| Автоплан | Зарплатный план, breakdown, применение |
| Контроль | Risk Radar, сигналы, смарт-офферы |
| Привычки | Геймификация, миссии, стрик |
| Цели | Накопления, прогресс |
| История | Фильтры по категориям и тегам |
| Счета | Оплата ЖКУ и подписок |
| AI-панель | Чат, подсказки, зарплатный режим |

### AI-ключ
Ключ Groq вшит в app.py. Для замены: `GROQ_API_KEY` в начале файла или переменная окружения.
